## 1. 概述

**桌面自动化工具** 是一款基于 Python 开发的桌面 GUI 自动化软件，主要用于机械性的测试工作。它不需要编写任何代码，通过可视化界面即可配置自动化步骤。

### 核心用途

- **识别按钮并点击**：通过图像匹配或 OCR 文字识别，自动找到按钮并点击
- **Excel 列名定位输入**：在 Excel 表格中识别列名，然后在对应位置输入特定数据
- **重复性表单填写**：自动在多个界面之间切换、输入数据
- **回归测试**：自动执行固定的 UI 操作序列，验证功能是否正常

### 技术原理

```
屏幕截图 → 图像匹配/OCR识别 → 定位目标 → 模拟鼠标键盘操作
```

- **图像匹配**: 使用 OpenCV 在屏幕截图中查找预先保存的参考图像
- **OCR 识别**: 使用 Tesseract 识别屏幕上的文字内容
- **输入模拟**: 使用 PyAutoGUI 模拟键盘输入和鼠标点击

### 架构概览

```

├── main.py              # 程序入口
```

## 2. 安装与环境配置

### 2.1 Python 环境

需要 Python 3.10 或以上版本。

```bash
# 检查 Python 版本
python --version
```

### 2.2 安装依赖

```bash
cd automation
pip install -r requirements.txt
```

依赖列表：

| 包名            | 版本要求    | 用途                   |
| ------------- | ------- | -------------------- |
| PySide6       | ≥6.5.0  | GUI 界面框架             |
| pyautogui     | ≥0.9.54 | 键盘鼠标模拟、图像匹配          |
| opencv-python | ≥4.8.0  | 增强图像匹配（confidence参数） |
| Pillow        | ≥10.0.0 | 图像处理、截图              |
| pytesseract   | ≥0.3.10 | OCR 文字识别（可选）         |
| pyperclip     | ≥1.8.2  | 剪贴板读写                |
| keyboard      | ≥0.13.5 | 全局热键监听               |
| pywin32       | ≥306    | Windows 窗口管理         |

### 2.3 安装 Tesseract-OCR（可选，OCR 功能需要）

OCR 文字识别功能需要单独安装 Tesseract-OCR 引擎：

1. 下载安装程序：[Home · UB-Mannheim/tesseract Wiki · GitHub](https://github.com/UB-Mannheim/tesseract/wiki)
2. 安装时勾选中文语言包（Chinese Simplified）
3. 将 Tesseract 安装目录添加到系统 PATH
4. 或者修改代码中指定路径：

```python
import pytesseract
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
```

### 2.4 启动程序

```bash
python main.py
```

## 3. 快速入门

### 3.1 创建第一个自动化项目

1. 启动程序后，点击 **➕ 新建项目** 按钮
2. 输入项目名称（如 "测试Excel数据录入"）和描述
3. 点击确定，自动进入项目编辑器

### 3.2 添加步骤

1. 在项目编辑器中，点击 **➕ 添加步骤**
2. 选择步骤类型（例如 "OCR文字识别点击"）
3. 配置步骤参数（例如：识别文字 = "列名A"）
4. 点击确定

### 3.3 运行

1. 点击 **▶ 运行** 按钮
2. 执行监控窗口弹出，实时显示执行进度和日志
3. 按 **ESC** 可随时紧急停止

### 3.4 常见工作流示例

**场景1：在 Excel 表格的特定列输入数据**

```
步骤1: OCR文字识别点击 → 识别列名"金额"，点击定位
步骤2: 图像相对坐标点击 → 以步骤1的位置为锚点，偏移到输入区域
步骤3: 输入文本 → 输入固定文本"12345"
```

**场景2：在软件中逐项勾选复选框**

```
步骤1: 图像匹配点击 → 点击第一个复选框的参考图像
步骤2: 输入文本 → 输入数据
步骤3: 键盘快捷键 → Tab 切换到下一个
```

## 6. 步骤类型详解

### 6.1 ⌨ 键盘快捷键

模拟按下组合键。

**快捷键录入方式**:

- **手动输入**: 直接在文本框输入组合键，用 `+` 连接，例如 `ctrl+c`
- **录制模式**: 点击 🎙录制 按钮，按下键盘组合键，滚动鼠标滚轮（也支持录制），鼠标点击结束录制

**参数：**

| 参数   | 说明                    | 示例                                     |
| ---- | --------------------- | -------------------------------------- |
| 快捷键  | 组合键，用 + 连接（支持手动输入或录制） | `ctrl+c`, `alt+tab`, `ctrl+wheel_down` |
| 按键间隔 | 按键之间的间隔时间             | 100ms（默认）                              |

**支持的按键名称：**

- 修饰键：`ctrl`, `alt`, `shift`, `win`
- 功能键：`f1`~`f12`
- 常用键：`enter`, `tab`, `esc`, `space`, `backspace`, `delete`
- 方向键：`up`, `down`, `left`, `right`
- 鼠标滚轮：`wheel_up`（向上滚动）, `wheel_down`（向下滚动）

### 6.2 🖼 图像匹配点击

在屏幕上查找指定图像，找到后点击其中心位置。

**参数：**

| 参数   | 说明                       | 默认值  |
| ---- | ------------------------ | ---- |
| 图像路径 | 参考图像文件路径（PNG/JPG/BMP）    | 必填   |
| 置信度  | 匹配置信度（0.5~1.0），越高越精确     | 0.90 |
| 点击类型 | left/right/middle/double | left |
| 灰度匹配 | 启用可提高速度约30%，但降低准确率       | 否    |

**参考图像制作建议：**

- 截取独一无二的特征区域（避免纯色大面积区域）
- 避免包含动态内容（时间、进度条等）
- 图片尺寸不宜过大（建议 50x50 ~ 200x200 像素）
- 使用内置截图工具精准截取

### 6.3 🖼 图像匹配(相对坐标)点击

先找到锚点图像，然后点击相对该图像中心的偏移位置。

**典型用例：**

- 找到 Excel 列名，然后点击列名下方第 N 行的单元格
- 找到按钮，然后点击按钮右侧的下拉箭头

**参数：**

| 参数   | 说明                 |
| ---- | ------------------ |
| 锚点图像 | 作为定位基准的图像          |
| 置信度  | 匹配置信度              |
| X 偏移 | 相对锚点中心的水平偏移（负值=左移） |
| Y 偏移 | 相对锚点中心的垂直偏移（负值=上移） |
| 点击类型 | 点击方式               |

### 6.4 📝 输入文本

在当前光标位置输入文本。

**文本来源：**

| 来源类型   | 说明             |
| ------ | -------------- |
| 固定文本   | 输入固定内容         |
| 循环轮数数字 | 根据当前循环轮数动态生成数字 |
| 剪贴板内容  | 输入系统剪贴板的当前内容   |

**循环轮数数字的配置：**

- **起始值**: 第一轮循环时输入的数字（默认1）
- **增量**: 每轮循环增加的值（默认1）
- 例如：起始值=10，增量=5 → 第1轮输"10"，第2轮输"15"，第3轮输"20"

### 6.5 ⏳ 等待图像出现

轮询等待指定图像出现在屏幕上，支持超时控制。

**参数：**

| 参数   | 说明      | 默认值           |
| ---- | ------- | ------------- |
| 等待图像 | 等待出现的图像 | 必填            |
| 置信度  | 匹配置信度   | 0.85          |
| 超时时间 | 最大等待时间  | 30000ms (30秒) |
| 检查间隔 | 轮询检查的间隔 | 500ms         |

### 6.6 🔤 OCR文字识别点击

使用 OCR 技术在屏幕上查找指定文字，找到后点击。

**参数：**

| 参数   | 说明            | 默认值         |
| ---- | ------------- | ----------- |
| 识别文字 | 要查找的文字（支持中英文） | 必填          |
| 语言   | OCR 语言代码      | chi_sim+eng |
| 置信度  | 文字匹配置信度       | 0.70        |
| X 偏移 | 相对文字位置的点击偏移   | 0           |
| Y 偏移 | 相对文字位置的点击偏移   | 0           |

**⚠️ 前提：** 需要安装 Tesseract-OCR（参见第2.3节）

### 6.7 ⏱ 等待

纯粹等待指定时间。

**参数：**

- **等待时间**: 100ms ~ 3600000ms (1小时)

### 6.8 🔀 条件判断

根据图像是否存在来决定后续的执行流程。

**参数：**

| 参数   | 说明                     |
| ---- | ---------------------- |
| 条件类型 | "图像存在时执行" / "图像不存在时执行" |
| 条件图像 | 用于判断的图像路径              |
| 置信度  | 匹配置信度                  |

## 7. 循环机制（步骤级 + 项目级）

项目支持**两层循环**嵌套，实现灵活的重复执行模式。

### 7.1 执行层级结构

```
项目循环 (项目设置 → 循环次数)
  └─ 步骤序列 (步骤1 → 步骤2 → ... → 步骤N)
       └─ 步骤级循环 (每个步骤可独立设置循环次数)
            ├─ 执行前等待
            ├─ 执行步骤动作
            └─ 执行后等待
```

### 7.2 步骤级循环

每个步骤在"高级设置"中可配置独立的**循环次数**（默认=1，表示执行一次不循环）。

**示例：**

- 步骤1: 键盘快捷键 (循环次数=1) → 执行1次
- 步骤2: 输入文本 (循环次数=5) → 重复执行5次后继续
- 步骤3: 等待 (循环次数=1) → 执行1次

执行顺序：步骤1(1次) → 步骤2(5次) → 步骤3(1次)

执行日志中会显示 `--- 步骤「输入数据」第 3/5 次 ---`。

### 7.3 项目级循环

项目设置中的"项目循环次数"控制整体步骤序列的重复轮数。

**示例：**

- 项目循环次数 = 3
- 步骤1(循环1次) → 步骤2(循环5次) → 步骤3(循环1次)

第一个项目循环：1→2(x5)→3  
第二个项目循环：1→2(x5)→3  
第三个项目循环：1→2(x5)→3

总执行次数 = 3轮 × (1 + 5 + 1) = 21 次步骤操作。

### 7.4 与输入文本的协作

输入文本步骤中使用"循环轮数数字"时，读取的是**项目级循环**的当前轮数（loop_index），方便在每轮循环中填入递增/递减的数字。

## 9. 运行与监控

### 9.1 执行监控窗口

## 13. 常见问题

### Q1: 图像匹配找不到目标？

**解决方法：**

1. 降低置信度（如从 0.90 降到 0.80）
2. 确保参考图像是屏幕的精确截图区域
3. 检查屏幕缩放大小的设置（100% 缩放效果最好）

### Q2: OCR 识别不到文字？

**解决方法：**

1. 确认已安装 Tesseract-OCR 并配置正确
2. 确认安装了对应的语言包
3. 降低置信度阈值

### Q3: 执行速度太快/太慢？

**解决方法：**

1. 调整项目设置中的"执行速度倍率"
2. 调整步骤的"执行前等待"和"执行后等待"

### Q4: 如何在不同分辨率的电脑上运行？

**解决方法：**

1. 将显示缩放都设置为 100%
2. 使用图像匹配（而非固定坐标）来定位目标

### Q5: 循环执行无法停止？

**解决方法：**

1. 按 ESC 键紧急停止
2. 将鼠标移到屏幕左上角（安全机制）
